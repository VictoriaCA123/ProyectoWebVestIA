#  VestIA  una Boutique la mas modernizada con IA 

**VestIA** es una aplicación web diseñada para que nuestros clientes puedan ver nuestro catalogo de ropa online pero ademas tiene su IA agrgada para que les ayude a encontrar sus prendas.

##  Funcionalidades Principales

* **Chatbot Inteligente:** Asistente virtual impulsado por la API de Google Gemini que responde dudas sobre moda, combinaciones y estilo en tiempo real.
* **Gestión de Perfil:** Sección de usuario personalizada para guardar preferencias y datos del usuario.
* **Catalogo de productos:** muestra todos los productos de la boutique
* **Carrito de productos:** puedes guardar tus productos con sus precios y cantidades 

##  Instalación y Visualización

Para probar este proyecto en tu computadora local:

**1. Clonar el repositorio**
Busca el botón verde que dice **"Code"** en la parte superior derecha de esta página. Al darle clic, encontrarás el link necesario para clonar el repositorio en tu computadora.

**2. Ejecución**
* Abre la carpeta del proyecto en **Visual Studio Code**.
* Asegúrate de tener descargada la extensión **"Live Server"**.
* Ve al archivo `index.html`, dale clic derecho y selecciona la opción **"Open with Live Server"**.
##  Tecnologías y Librerías Utilizadas

Este proyecto fue desarrollado utilizando tecnologías web estándar:

* **HTML5:** Estructura semántica del sitio.
* **CSS3:** Estilos, diseño responsivo y animaciones.
* **JavaScript :** Lógica del frontend y manejo del DOM.
* **Google Gemini API:** Para el procesamiento de lenguaje natural del chatbot.
* **Git & GitHub:** Control de versiones.
